# Protocolos de Seguridad

## Protocolos de Encriptación

- **AES-256**: Utilizado para encriptar datos sensibles.
- **RSA**: Utilizado para la encriptación asimétrica de claves.

## Protocolos de Autenticación

- **OAuth 2.0**: Utilizado para la autenticación de usuarios.
- **JWT**: Utilizado para la generación y verificación de tokens de acceso.

## Protocolos de Comunicación

- **HTTPS**: Utilizado para todas las comunicaciones externas.
- **SSH**: Utilizado para el acceso remoto seguro a servidores.

## Prácticas Recomendadas

- **Rotación de Claves**: Rotar las claves de encriptación periódicamente.
- **Monitoreo Continuo**: Monitorear continuamente el tráfico de red en busca de actividades sospechosas.
- **Actualizaciones Regulares**: Mantener todos los sistemas y dependencias actualizados.
